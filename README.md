# Do_an_CSN_Bootstrap

Đề tài Cơ sở ngành: Tìm hiểu và ứng dụng Bootstrap trong thiết kế giao diện Web Responsive.

## Cấu trúc dự án (đa trang)
- `index.html` — Trang chủ: giới thiệu Bootstrap.
- `grid.html` — Hệ thống Grid: lý thuyết + thực hành.
- `components.html` — Components: Navbar, Card, Modal, Accordion, Alert, Badge.
- `utilities.html` — Utility Classes: spacing, màu sắc, flexbox, display.
- `evaluation.html` — Đánh giá ưu điểm, hạn chế, so sánh với CSS thuần.
- `feedback.html` — Thực hành biểu mẫu + tài liệu tham khảo.
- `style.css` — CSS tùy biến theo màu nhận diện TVU.

Mở `index.html` bằng trình duyệt để chạy dự án (không cần server, chỉ dùng CDN cho Bootstrap 5.3 và Bootstrap Icons).
